

# 🗳️ TN 2021 Elections Analysis Dashboard

Over a weekend, I decided to explore a real-world political dataset and build a tool that could help make electoral insights more accessible and actionable — especially for political strategists and analysts.

This project is a data-driven dashboard that provides an in-depth analysis of the **Tamil Nadu 2021 Legislative Assembly Elections**.

## 🚀 Project Overview

I scraped the election data from **Wikipedia**, performed **data cleaning**, and built a **data model** to organize and analyze the results. The goal was to answer business-relevant questions that could guide campaign strategies and electoral research.

### ✅ Key Features

- **Low Margin Wins**  
  Identify constituencies where the **winning party won by a very small vote margin** — a crucial insight for strategists looking to focus efforts on swing regions.

- **Constituency-Level Insights**  
  On selecting a constituency, the dashboard shows:  
  - Winning party & candidate  
  - Runner-up party  
  - Vote counts for both  
  - Vote margin

- **Alliance-Wise Analysis**  
  Understand how different alliances performed across the state in terms of seat share.

- **Region-Wise Analysis**  
  See which alliance performed best in various regions of Tamil Nadu (e.g., Western region, Central region, etc.).

- **User-Friendly & Interactive**  
  The dashboard is built to be intuitive and engaging, making it useful not just for strategists, but also for **common voters, political analysts, and data enthusiasts**.

## 💡 Use Cases

- Political strategists can focus on **constituencies with close contests**.
- Analysts can derive insights from **regional performance trends**.
- Voters can get a **360° view** of how their region and constituency performed.

## 📊 Tech Stack

- **Data Collection**: Web Scraping on PowerBI
- **Data Cleaning & Modeling**: `Pandas`, `NumPy`
- **Visualization & Dashboard**: PowerBI
